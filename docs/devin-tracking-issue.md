# Implement an opt-in Devin integration pilot

ReleaseGuard already exports a pinned task contract and captures before-and-after reproduction evidence. This issue tracks the provider transport and controls needed to trial approved investigation, repair, and validation on an isolated pilot repository.

- [ ] Verify provider support for disposable workspaces, credential and egress isolation, termination, and structured results.
- [ ] Bind repository enrollment and approvals to the full task digest, phase, allowed paths, base SHA, and expiry.
- [ ] Add idempotent dispatch and status reconciliation, with server-side budgets and cancellation.
- [ ] Start a read-only investigation pilot approved by repository maintainers.
- [ ] Add a separate repair approval and independent check of the actual Git diff, tests, and evidence.
- [ ] Require a human to approve a draft PR and record the final decision. Keep merge and deployment outside the integration.
- [ ] Publish sanitized pilot findings and operational runbooks.

The handoff and result schemas, CI workflows, and replay lab in this repository are the baseline for the pilot.
